What leaves this machine

Your files and the file index stay on this computer. With the default local brain (Gemma through Ollama), file names, file contents and the model's reasoning never leave it. Voice, web search, the cloud browser, memory and error tracing are cloud services, listed below. Turn voice off and skip web tools, and a request makes no network call at all.

Never stored in the cloud: file paths, file names, file contents, request text, web addresses, device names, API keys.
